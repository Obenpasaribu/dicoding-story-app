Catatan API Key
===============

Aplikasi ini menggunakan Leaflet sebagai library peta digital dengan tile layer:

1. OpenStreetMap Standard - https://{s}.tile.openstreetmap.org/{z}/{x}/{y}.png
2. Esri World Imagery (satelit) - https://server.arcgisonline.com/ArcGIS/rest/services/World_Imagery/MapServer/tile/{z}/{y}/{x}

Kedua tile provider di atas bersifat publik dan TIDAK memerlukan API key,
sehingga tidak ada API key yang perlu disertakan pada berkas ini.

Story API yang digunakan:
Base URL: https://story-api.dicoding.dev/v1
(API ini juga tidak memerlukan API key, hanya token hasil login untuk endpoint yang membutuhkan autentikasi.)
